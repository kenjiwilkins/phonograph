# Spotify brand assets

`Spotify_Full_Logo_White.svg` is `Full_Logo_White_RGB.svg` from the official
"Full logo" download (https://developer.spotify.com/documentation/design, "Using our logo"),
unmodified. The white variant is the one the guidelines specify for dark backgrounds.

Rules from the guidelines:

- Never redraw, recolour, stretch, rotate or crop the logo.
- Minimum size: 70px wide in digital use (the app renders it at 80px).
- Exclusion zone: half the height of the icon on every side.
- Use is covered by the Spotify Developer Terms of Service; the logo remains Spotify's trademark.
